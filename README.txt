STORAGE FINDER (Fabric 1.21.11)

BUDOWANIE:
1. Zainstaluj Javę 21 (JDK) i IntelliJ IDEA.
2. Otwórz folder "storagefinder" w IntelliJ (File > Open) i poczekaj na import Gradle.
3. W terminalu IntelliJ:  gradle build   (lub ./gradlew build, jeśli masz wrapper)
   Gotowy plik: build/libs/storagefinder-1.0.0.jar
4. Wrzuć jar do .minecraft/mods razem z Fabric API.

Klawisz K = menu moda.
